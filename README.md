# Sigma.Novosibirsk

Веб-сайт для летней научно-образовательной школы «Сигма.Новосибирск».

## О проекте

Платформа предназначена для:
- организации работы школы в одном месте;
- управления курсами и расписанием;
- разделения доступов для администратора, преподавателей и студентов;
- поддержки регистрации, обучения и обратной связи.

## Роли пользователей

- **Администратор** — управляет процессами школы и доступами.
- **Преподаватель** — ведет курсы и работает со своими учебными данными.
- **Студент** — выбирает курсы и участвует в учебном процессе.

## Ключевые сценарии

1. Преподаватель подает заявку на участие.
2. Администратор одобряет доступ преподавателя.
3. Публикуются курсы и учебное расписание.
4. Студенты выбирают курсы и посещают занятия.
5. Ведется учет посещаемости и результатов.
